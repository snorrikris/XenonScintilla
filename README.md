# XenonScintilla
Scintilla edit control for XenonFramework

## This is a "fork" of the official Scintilla source code
This repo was created by unzipping the https://www.scintilla.org/scintilla566.zip into this repo.

Because no official Scintilla git repo exists - I chose to do it like this - because I need to make tiny changes to the source code to suit my needs.

### This repo exists because Scintilla is used as edit control in the XenonFramework

See: https://github.com/snorrikris/XenonFramework

This repo is a sub-module in the XenonFramework project.
